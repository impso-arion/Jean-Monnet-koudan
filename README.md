# 講談　ジャン・モネ物語

ジャン・モネの一生を、講釈の口調で語った全八席。

戦争を「悪いことじゃ」と説教しても千年止まらぬ。ならば、戦争をやめたほうが得、始めたほうが損、という勘定を先に組む。フランスの鉄とドイツの石炭を、どちらのポケットにも入らぬ第三者の箱へ入れ、戦車を商売として作れなくした男の話である。

聞き手が歴史の前提を知らなくても追えるよう、情景と説明を厚くしてある。声に出して読むのが、この文章の読み方である。

筋は通った。残っている仕事は校正である。人が読んで引っかかった箇所を、講釈の口調のまま直す。

## 読み方

第一席から順に読む。あとの席は、前の席を前提にしている。

講釈を聞くつもりで読む。解説書を採点するつもりでは読まぬ。わからない、話が跳ぶ、誰の話かわからない、比喩が現場を隠す、と感じたところで止める。指摘の渡し方は [校正手順.txt](校正手順.txt) にある。

## 書く前の見方

[起点.txt](起点.txt) は講釈そのものではない。この物語を書く前に置いた関心のメモである。

モネを、王家や軍事力で押す支配の次に、経済の利害・物流・法の手続きで統合を組んだ設計者として読む。切り口は四つ。

1. 完成した提案書で、相手の逃げ道を消して動かす交渉
2. 第二次大戦で、アメリカの生産を一つの戦争遂行の計画へ束ねた実務
3. 欧州石炭鉄鋼共同体。戦車を禁ずるのではなく、鉄と石炭の共同管理で作れなくする
4. その思考を、いまの仕組みの組み替えに使う枠

本文は、このメモの用語をそのまま出さない。聞き手が一度で追える言葉に置き換えてある。

## 校正

手順は [校正手順.txt](校正手順.txt)。

人が全文を先に直すのではない。人が聞き手として読み、わからない箇所だけを渡す。直す側は、指摘を受けてから動く。

直してよいのは、主語、現場を飛ばした比喩、跳んだ場面、そして同じ病が近くにある箇所である。席の順番、事実の芯（日付、人物、何をしたか）、講釈の口調は動かさない。
